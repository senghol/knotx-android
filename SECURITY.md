# Security Policy

Security is important to KnotX. We appreciate the work of security researchers and developers who help us identify and fix vulnerabilities.

## Reporting a Vulnerability

If you discover a security vulnerability in KnotX, please report it responsibly.

Please do not disclose security vulnerabilities publicly before giving us an opportunity to investigate and address them.

Include the following information in your report:

- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential security impact.
- Relevant logs, screenshots, or proof of concept, if available.

Please avoid including real users' private messages, credentials, or personal information.

## Scope

This policy covers the publicly available KnotX Android client, including:

- End-to-end encryption implementation.
- Cryptographic key management.
- Local data storage.
- Authentication and session handling.
- Message handling and network communication.
- Other security-sensitive Android functionality.

The backend and server-side infrastructure are proprietary and are not included in this repository.

If you discover a vulnerability involving the backend, you may still report it through the contact method below.

## Reporting Contact

Security reports: [admin@senghol.com]

Please use a private reporting channel rather than opening a public GitHub issue.

## Our Commitment

We will review responsible vulnerability reports, investigate valid issues, and work towards fixing confirmed vulnerabilities.

We appreciate everyone who helps make KnotX safer.

Thank you for helping protect KnotX users.
