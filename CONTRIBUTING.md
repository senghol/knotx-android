# Contributing to KnotX

Thank you for your interest in contributing to KnotX!

We welcome developers, testers, and anyone who wants to help improve the project.

## Before You Start

- Read the project README.
- Check existing issues before reporting a bug or proposing a change.
- For major changes, open an issue first to discuss the idea.

## Reporting Bugs

When reporting a bug, please include:

- A clear description of the problem.
- Steps to reproduce it.
- Expected and actual behaviour.
- Android version and device details.
- Relevant logs or screenshots, after removing personal information.

## Submitting Code

1. Fork the repository.
2. Create a branch for your changes.
3. Make your changes and test them.
4. Commit your work with a clear commit message.
5. Push your branch to your fork.
6. Open a pull request against the `main` branch.

## Code Guidelines

- Follow the existing Kotlin and Jetpack Compose conventions.
- Keep changes focused and easy to review.
- Avoid introducing unnecessary dependencies.
- Do not commit API keys, credentials, signing keys, or personal information.
- Include relevant tests where possible.

## Security Issues

Please do not report security vulnerabilities through public issues. Follow the instructions in [SECURITY.md](SECURITY.md).
