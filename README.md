# KnotX Android

KnotX is a privacy-focused messaging application built in India by Senghol Technologies Private Limited.

The idea is simple: messaging without unnecessary distractions. No advertisements, no promotions, and we don't sell your data.

Every notification should be a real message from a real person. Open it, talk, close it.

## Features

- End-to-end encrypted personal chats
- End-to-end encrypted group chats
- Voice and video calls
- Message reactions, editing and deletion
- Media sharing
- Live location sharing
- Polls
- Digital Khata (Bayaka)
- In-chat GST billing
- Dark mode and customizable themes

## Availability
